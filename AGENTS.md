# Project Guide

## Stack and Structure

- This project uses Next.js with the App Router and TypeScript.
- `app/page.tsx` implements the home route, `app/layout.tsx` defines the root layout and metadata, and `app/globals.css` contains global styles.
- `next-env.d.ts` and `.next/` are generated by Next.js; do not edit generated files by hand.

## Working Conventions

- Follow the conventions already established in the project and keep changes scoped to the requested task.
- Keep the page server-rendered unless browser-side interactivity is needed.
- Keep dependency manifests and lockfiles synchronized when changing dependencies.

## Commands

- `npm run dev` starts the development server.
- `npm run build` runs the production build and TypeScript checks; use it to validate changes.
- `npm start` starts the production server after a successful build.
